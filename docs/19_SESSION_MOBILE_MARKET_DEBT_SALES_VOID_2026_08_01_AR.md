## 5) دين السوق (بلا عملاء)

### المعادلة (مستوى الشركة)

```
صافي دين السوق = رصيد افتتاحي
               + Σ مبيعات على الحساب (من تاريخ البداية)
               − Σ تحصيل نقدي (من تاريخ البداية)
```

- الشيكات **خارج** المعادلة.
- الصافي السالب يُعرض كـ **فائض تحصيل**.
- لا ربط بعملاء/فواتير ERP.

### الملفات والمسارات

| بند | قيمة |
|-----|------|
| المسار | `GET /market-debt` — `market-debt.index` |

| الجدول | `market_debt_settings` (سجل إعدادات واحد) |
| الخدمة | `App\Services\MarketDebtService` |
| الواجهة | `App\Livewire\MarketDebtPage` |
| اختبارات | `tests/Feature/MarketDebtTest.php` |

## 6) حذف/إلغاء بيع في سجل المبيعات

| بند | قيمة |
|-----|------|
| المسار | `/sales` — `SaleList` |
| من يحذف؟ | صلاحية `delete-sales` = محاسب/مدير نشط |
| السائق | يرى السجل؛ **لا** زر حذف |
| ماذا يحدث؟ | Soft-delete للبيع + إرجاع الكمية للمخزن/السيارة + حركة `adjustment` بملاحظة `إلغاء بيع #id` |
| الأثر المالي | صندوق السائق ودين السوق يُحسبان من المبيعات غير المحذوفة → يتحدّثان تلقائياً |
| الخدمة | `SalesService::voidSale()` + `InventoryService::restoreForVoidedSale()` |
| اختبارات | `tests/Feature/SaleVoidTest.php` |

> تحذير: حذف صف البيع وحده دون إرجاع المخزون كان سيُفسد الأرصدة — التنفيذ يفرض الاثنين في معاملة واحدة.
