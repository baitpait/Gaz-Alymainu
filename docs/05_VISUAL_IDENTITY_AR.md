# الهوية البصرية — غاز اليمني (Gaz Al-Yamani)

> **لغة الواجهة:** النظام **عربي فقط** (RTL). النص الإنجليزي `Gaz Al-Yamani` للمرجع الخارجي والطباعة التقنية فقط.

## 1) تحليل الشعار

### 1.1 الملفات الرسمية

| الملف | الاستخدام |
|--------|-----------|
| `branding/logo-mark.svg` | المصدر المتجه — أيقونة فقط (أسطوانة + لهب) |
| `branding/logo-full.svg` | المصدر المتجه — شعار كامل مع الاسم العربي |
| `branding/logo-mark-light.svg` | أيقونة للخلفيات الداكنة (صفحة الدخول) |
| `public/branding/logo.png` | PNG شفاف — الهيدر والواجهة |
| `public/branding/logo-print.png` | PNG 512px — PDF والفواتير |
| `public/branding/logo-full.png` | PNG — ترويسات مطبوعة |
| `public/favicon.png` | أيقونة المتصفح |

> **تصدير PNG:** `npm run branding:export` (يقرأ SVG من `branding/` ويكتب إلى `public/`).

### 1.2 الرمز (العلامة المختصرة)

- **أسطوانة غاز:** جسم رمادي `#3D3D3D` — يرمز بالمنتج الأساسي (أسطوانات LPG).
- **حلقة وصمام ذهبيان:** `#C9A227` — تميز العلامة ويربط بالهوية المؤسسية.
- **لهب ذهبي:** تدرج من `#F5D76E` إلى `#A8841A` — طاقة، حرارة، غاز.
- **خلفية شفافة:** يعمل على الأبيض (لوحة التحكم) والأسود (صفحة الدخول).

### 1.3 الاسم الكتابي (Wordmark)

- **عربي:** «**غاز اليمني**» — الاسم الرسمي في كل الواجهات.
- **شعار فرعي:** «**توزيع الغاز**» — بالذهبي `#C9A227`.
- **إنجليزي (مرجع):** `Gaz Al-Yamani` — في `.env` كـ `COMPANY_DISPLAY_NAME`.

### 1.4 الدلالة

- **الموثوقية:** أسطوانة واضحة = منتج حقيقي، ليس رمزاً مجرداً.
- **الطاقة:** اللهب = غاز وحرارة.
- **الهوية المحلية:** الاسم العربي «غاز اليمني» في المقدمة.
- **الاحتراف:** ألوان هادئة (ذهبي + رمادي) مناسبة للتقارير المالية ولوحة التحكم.

## 2) لوحة الألوان

| Token | HEX | الاستخدام |
|--------|-----|-----------|
| `--color-brand-gold` | `#C9A227` | أزرار أساسية، شعار فرعي، تمييز |
| `--color-brand-gold-light` | `#E8C547` | تدرجات اللهب، hover |
| `--color-brand-gold-dark` | `#A8841A` | ظلال، تدرج سفلي |
| `--color-brand-grey` | `#3D3D3D` | نصوص، أسطوانة، عناوين |
| `--color-surface` | `#FFFFFF` | خلفية الهيدر والبطاقات |
| `--color-surface-muted` | `#F0F2F5` | خلفية الصفحات |
| `--color-border` | `#E2E4E9` | حدود |
| `--color-danger` | `#DC2626` | أخطاء / حذف |
| `--color-success` | `#16A34A` | نجاح / تسوية |

**التباين (WCAG):** النص الطويل بالرمادي `#3D3D3D` على الأبيض؛ الذهبي للتمييز والأزرار وليس للفقرات.

## 3) الطباعة

- **الخط:** **Cairo** (Google Fonts) — مستخدم في `resources/css/app.css`.
- **الاتجاه:** `dir="rtl"` على الجذر.
- **الأوزان:** عناوين 700–800؛ نص 400–500؛ أرقام LTR داخل الخلايا.

## 5) مكوّنات الواجهة

- **الهيدر:** `logo.png` (32px ارتفاع) + اسم + شعار فرعي ذهبي.
- **صفحة الدخول:** `logo-mark-light.png` على خلفية `#0f0f0f`.
- **PDF / فواتير:** `logo-print.png` (512px) + `$companyName` من الإعدادات.
- **Favicon:** `favicon.png` من العلامة المختصرة.
