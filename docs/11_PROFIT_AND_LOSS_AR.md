# قائمة الربح والخسارة — غاز اليمين

## التقارير الثلاثة

| المسار | الوصف |
|--------|--------|
| `/reports/profit-loss` | **كامل** — استحقاق + تكلفة المباع |
| `/reports/profit-loss-cash` | **بدون دين (نقدي)** — إيراد نقدي + COGS للمبيعات النقدية |
| `/reports/profit-loss-ils` | **بالشيكل** — تحويل BOI لنفس المعادلة |

## المعادلة (لكل عملة منفصلة)

**كامل:**
```
صافي = (فواتير عملاء + مبيعات سائقين) − تكلفة المباع − مصروفات − رواتب مدفوعة
تكلفة المباع (COGS) = Σ (كمية البيع غير الملغى × تكلفة الصنف ILS)
```

**بدون دين:**
```
صافي = (دفعات عملاء + تحصيلات + مبيعات نقدية) − COGS(المبيعات النقدية) − مصروفات − رواتب
```

**أصل المخزون (خارج الربح):**
```
أصل المخزون = Σ (رصيد حالي بكل المخازن × تكلفة الصنف)
```

- مثال: شراء 100 وبيع 50 بتكلفة 80 وبيع 100 → ربح = 5000 − 4000 = 1000؛ المتبقي أصل = 4000.
- **فواتير تقييم المخزون** (`purchase_orders.is_inventory_valuation = true`) **لا تدخل** الصافي ولا تُحسب كمشتريات تشغيلية.
- مشتريات تشغيلية تُعرض كمرجع فقط في تبويب كامل ولا تُطرح من الصافي (الصافي يعتمد COGS).
- **العملة الافتراضية** في الواجهة: **ILS**.
- **الرواتب** من `salary_payments` فقط (`status=paid`).
- جلسة: `docs/21_…`، `docs/22_…`، `docs/23_SESSION_COGS_DASHBOARD_PROFIT_2026_08_09_AR.md`.
- **لوحة التحكم:** بطاقة «أرباح اليوم» = نفس معادلة «كامل» لفترة يوم واحد (`DashboardSummaryService`).
